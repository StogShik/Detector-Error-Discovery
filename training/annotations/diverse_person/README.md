# Дополнительная разметка сложных поз TRAIN

Вручную проверены 62 новых кадра дней 25–26 октября и 129 наблюдений людей. Это визуальная разметка ассистента с исходными подсказками детектора, а не новая разметка организаторов или второго человека-аннотатора. Координаты не переносились из соседних GT-кадров.

Отбор использовал разнообразие замороженных DINOv2-признаков фрагментов. Между новыми кадрами одного дня — не менее 5 минут; от ранее размеченных кадров — не менее 3 минут. После просмотра дополнительно помечены повторяющиеся позы. Это разнос кадров и визуальное разнообразие, а не гарантия статистической независимости людей и сцен.

## Файлы и координаты

- `observations.csv`: все 129 наблюдений, видимая граница, поза и решение о пригодности полного бокса.
- `geometry_boxes.csv`: 42 бокса после исключения повторяющихся поз. Это разреженные объектные аннотации, не полная разметка каждого кадра.
- `manual_review.json`: редактируемые результаты визуального просмотра в нативных пикселях.
- `frames.csv`: исходные кадры, время, размеры, число проверенных людей.
- `visible_people.coco.json`: COCO с отдельной категорией `person_visible`. Его `bbox` описывает видимую границу, а не предполагаемое скрытое тело.
- `initial_proposals_native.csv`: исходные подсказки до исправлений и удаления дублей.
- `image_sha256.json`, `previously_annotated_frames.csv`, `policy.json`: проверка источников, разнесения кадров и правил.

Исходные дополнительные JPEG имеют размер **640×360**. Поля `native_*` и координаты COCO — в этом пространстве. Поля `visible_x1…visible_y2` и `x1…y2` в CSV — канонические **1280×720**, то есть вдвое больше нативных координат. YOLO-поля `cx,cy,w,h` нормализованы.

У 57 наблюдений границы бокса подтверждаются видимыми крайними частями тела или границей изображения; 15 из них исключены как повторяющиеся позы. У оставшихся **72** наблюдений скрытый полный охват неизвестен: поля полного бокса оставлены пустыми. Ноги за столом не дорисовывались. Рабочий запас погрешности указан как 4 нативных пикселя; это не измеренная гарантия точности аннотатора.

После исправления `manual_review.json` можно заново получить CSV и COCO:

```bash
uv run python training/export_diverse_annotations.py
```

## Безопасная подготовка обучения

Нельзя передавать `geometry_boxes.csv` обычному детектору как полную покадровую разметку: другие реальные люди на том же изображении тогда стали бы ложными отрицательными примерами.

```bash
uv run python training/diverse_person_data.py --data-dir /path/to/DATA_DIR --prepare
```

Подготовка сохраняет исходный масштаб кадра. Люди с неизвестными полными границами закрываются прямоугольниками по видимой части с запасом 3 пикселя. Если такое закрытие затрагивает более 3% любого подтверждённого бокса, кадр исключается. Получаются **20 дополнительных кадров с 24 полными целями** плюс исходные кадры и 82 исходных GT-бокса. Частично скрытые люди не получают выдуманных полных целей. Исходные JPEG остаются неизменными, модифицированные копии записываются в `outputs/`.

Проверка без подготовки изображений:

```bash
uv run python training/diverse_person_data.py --data-dir /path/to/DATA_DIR
```

Она проверяет хеши всех 62 изображений, масштаб координат, допустимые даты, отсутствие TEST и прежних кадров, временные расстояния и пустые полные цели для неопределённых случаев.

## Проверка влияния на модель

```bash
# Быстро воспроизвести сравнение по сохранённым OOF-детекциям:
uv run python training/train_diverse_person.py --stage evaluate

# Повторить обучение и проверку с исключением целого дня:
uv run python training/train_diverse_person.py --stage cv --data-dir /path/to/DATA_DIR
```

Контроль без новых данных и вариант с новыми данными получают одинаковое число примеров и шагов оптимизатора. Используются только противоположный TRAIN-день и его warm start. Без `--warm-start-dir` скрипт восстанавливает warm start из публичного YOLO11s и ранее включённой TRAIN-разметки; повторное нейросетевое обучение может отличаться численно на другом устройстве.

Дообучение текущего детектора: 6 эпох, backbone freeze=10, lr=0.0001, imgsz=640; проверка imgsz=960. Замена person-ветки дала AP людей **0.94430 / 0.83982** против **0.94430 / 0.85558** исходной схемы. Средний общий AP: **0.95607** против **0.95795**. Другие проверенные варианты тоже не прошли критерий устойчивого улучшения. Разметка добавлена как отдельный набор; рабочие веса и стандартная схема сохранены, нового тестового CSV этот эксперимент не создаёт.
